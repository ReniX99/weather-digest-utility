# Консольная утилита "Погодный дайджест" на Node.js

Утилита принимает список городов и количество дней и выдаёт прогноз из открытого REST API и сохраняет отчёт в файлы.

## Требования

Для запуска приложения необходимо установить:

- Git
- Node.js **20+**
- npm **10+**

## Установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/ReniX99/weather-digest-utility.git
```

### 2. Переход в директорию проекта
```bash
cd <project-name>
```

### 3. Установка зависимостей
```bash
npm install
```

## Настройка окружения

Создайте файл `.env` в корневой директории проекта. Используйте файл `.env.example` как шаблон
```env
GEOCODING_API_URL= ... # URL API координат
FORECAST_API_URL= ... # URL API погоды по координатам

REQUEST_TIMEOUT= ... # Время ожидания запроса
```

## Запуск приложения

```bash
node src/index.js --city "Москва, Екатеринбург" --days 4
```

## Структура проекта

```bash
project/
├── docs/postman  # Тестирование API в Postman
├── reports/ # Отчёты о прогнозах погоды
├── src/
    └── api/
        └── open-meteo.js # Запросы к API
    └── cli/
        └── forecast.js # Обработка переменных командной строки
    └── format/
        └── forecast.js # Вывод в консоль
    └── storage/
        └── cache.js # Получение кэша погоды
        └── report.js # Запись отчёта погоды в файл
├── index.js # Исполняемый файл
├── .env # Переменные окружения
```
